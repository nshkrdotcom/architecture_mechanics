# Architecture Mechanics

A controlled synthetic laboratory for measuring how sequence-mixing and
state-writing mechanisms change feature geometry and causal legibility.

> Given matched small models and synthetic tasks with known ground-truth
> features, how do alternative sequence-mixing and state-writing mechanisms
> change feature packing, cross-token transport, overwrite behavior, and
> causal legibility?
